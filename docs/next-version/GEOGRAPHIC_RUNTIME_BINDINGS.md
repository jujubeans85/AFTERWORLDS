# Geographic source bindings

The four additional geographic worlds retain their exact frozen source datasets. They do not change the accepted electricity-access geography or its release digest.

Country joins reuse the pinned UN M49-to-ISO audit and Natural Earth 1:110m boundary file already used by concept 408. Joins use explicit numeric identities, never country-name guessing, parent-territory merging or inherited values. The same Cyprus and Somalia scope exclusions remain explicit. Concept 375 maps all five inventor locations; 247 maps all fourteen named programme partners; 78-4 maps 167 of 217 reporting economies, leaving fifty table-only. Context land has no invented value.

Concepts 375 and 78-4 carry `geography.countries[].displayAnchor` with `lat`, `lon` and a literal display-only meaning. The deterministic algorithm unwraps polygons, considers the largest polygon first, and searches progressively finer interior grids near its bounding-box centre. The validator checks that each anchor lies inside the joined polygon, respecting holes. Anchors are included in the geography digest and immutable release. They never replace a source row's null latitude or longitude and must be labelled country summaries, not observed facilities, inventor addresses or local density.

Concept 378 uses only the source's published randomized recorder coordinates. The adapter retains 1,587 rows: 529 for each of three species, twenty-seven sites and source weeks 10–30. Each species has 260 explicit missing-effort rows; the additional thirty-eight absent combinations per species do not become new source rows. Detection is binary and source-modelled; automated counts are not individual birds. Effort is a separate 0–1 fraction. Site coordinates remain identical across the source records, and the public ±0.01-degree randomization remains disclosed. No polygon join or invented recorder location is used.

Concept 78-4 retains the two original same-year inputs independently. A count is available only when population and Internet-use percentage are both present; all 182 paired counts reproduce population × percentage / 100. Thirty-five counts remain null. Percentage mode may still show an available percentage when its population input is missing. Count disks use area, not radius, proportional to the source-derived count; polygon colour uses the native 0–100 percentage scale. Covered economies are not a complete world-population total.

The release builder and streamed browser reader both enforce the existing 2,000,000-byte bound. At the 61-view checkpoint, the largest new source release, recorder observations, is 1,414,852 bytes. Tests cover source coverage, native units, missing-versus-zero, count formulas, polygon-interior anchors, invalid joins and existing 408 regressions. Scene tests separately cover filtered observation identity, source-coordinate selection, country modes and phase-invariant geometry.
